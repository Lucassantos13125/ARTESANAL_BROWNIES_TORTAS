# ARTESANAL BROWNIES & TORTAS

Site vitrine/e-commerce seguindo a estrutura do projeto Valdino Bolos Caseiros.

## Arquivos
index.html, cardapio.html, brownies.html, tortas.html, carrinho.html, styles.css, script.js, produtos.js e images/logo.png.

## Fotos dos produtos
Coloque na pasta `images`:
- brownie-tradicional.jpg
- brownie-Nutella.jpg
- brownie-Ninho.jpg
- brownie-Leite.jpg
- torta-frango.jpg

O site possui fallback por emoji caso uma foto ainda não exista.
